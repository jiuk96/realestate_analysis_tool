# 점프! 점프! 🐸

두들 점프 스타일의 무한 점프 웹 게임입니다. 순수 HTML5 Canvas + JavaScript로 만들어져 의존성이 없고, PWA를 지원해 폰 홈 화면에 앱처럼 설치할 수 있습니다.

## 플레이 방법

| 조작 | 모바일 | PC |
|------|--------|-----|
| 좌우 이동 | 화면 좌/우 터치 또는 기기 기울이기 | ← → 방향키 |
| 발사 | 화면 상단(위쪽 25%) 탭 | 스페이스바 |
| 일시정지 | 우상단 ❚❚ 버튼 | ESC |

## 게임 요소

- 🟢 **초록 발판**: 일반 발판
- 🔵 **파란 발판**: 좌우로 움직임
- ⚪ **흰 발판**: 한 번 밟으면 사라짐
- 🟤 **갈색 발판**: 밟으면 부서짐 (튕기지 못함)
- 🔴 **스프링**: 더 높이 점프
- 🟠 **제트팩**: 잠시 동안 빠르게 상승
- 👾 **몬스터**: 위에서 밟거나 총알로 처치. 옆이나 아래에서 부딪히면 게임 오버

높이 올라갈수록 발판 간격이 넓어지고 특수 발판·몬스터가 늘어나며, 배경이 하늘에서 우주로 변합니다.

## 캐릭터 교체 방법

`assets/character/` 폴더에 아래 PNG 파일을 넣으면 자동으로 적용됩니다 (투명 배경 권장, 정사각형 비율 권장):

| 파일명 | 설명 | 필수 여부 |
|--------|------|-----------|
| `jump-left.png` | 왼쪽을 보는 기본 모습 | ✅ 필수 |
| `jump-right.png` | 오른쪽을 보는 모습 | 선택 (없으면 좌우반전) |
| `shoot.png` | 위로 발사할 때 모습 | 선택 |

파일이 없으면 내장된 임시 캐릭터(초록 두들이)가 그려집니다.

## 로컬에서 실행

```bash
cd game
python3 -m http.server 8000
# 브라우저에서 http://localhost:8000 접속
```

## 배포

`claude/doodle-jump-game-dev-jvgm8d` 브랜치의 `game/` 폴더에 변경이 push되면
GitHub Actions(`.github/workflows/deploy-game.yml`)가 자동으로 `gh-pages` 브랜치에 배포합니다.

배포 주소: **https://jiuk96.github.io/realestate_analysis_tool/**

> 최초 1회, 저장소 Settings → Pages 에서 Source가 `gh-pages` 브랜치로 잡혀 있는지 확인이 필요할 수 있습니다.

## 폰에 앱처럼 설치 (PWA)

- **iPhone (Safari)**: 공유 버튼 → "홈 화면에 추가"
- **Android (Chrome)**: 메뉴 → "홈 화면에 추가" 또는 설치 배너

설치하면 전체 화면으로 실행되고, 오프라인에서도 플레이할 수 있습니다.
